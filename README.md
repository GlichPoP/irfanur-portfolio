A modern, high-performance portfolio website presenting my production software engineering projects, technical skill matrix, and architecture case studies.

Built with **zero build step**, zero third-party dependencies, and pure web standards (HTML5, modern CSS3 with CSS custom properties, and vanilla ES6+ JavaScript). Hosted for free on **GitHub Pages**.

---

## 🌟 Highlights & Featured Work

- **PROBAHO CRM Solutions**: Offline-first enterprise management suite built with Electron, React 19, and SQLite (sql.js) featuring sub-millisecond local queries, automated background update delivery via GitHub CDN, and multi-region logistics.
- **Interactive System Architecture**: Real-world operational case studies detailing problem statements, architectural tradeoffs, and performance achievements.
- **Responsive & Accessible**: Fluid typography, dark/light theme switching with persistence, touch-optimized layouts, and accessible semantic markup.

---

## 💻 Tech Stack

- **Markup & Layout:** Semantic HTML5, CSS Grid, Flexbox, Glassmorphism
- **Design Tokens:** Dynamic CSS variables with automatic dark/light theme detection
- **Interactions:** Vanilla JavaScript (ES6+), Clipboard API, Intersection/ScrollSpy
- **Hosting:** GitHub Pages (Instant Global CDN, Zero Hosting Cost)

## 🚀 Local Development

No package installation or bundler required:

1. Clone the repository:
   ```bash
   git clone https://github.com/GlichPoP/irfanur-portfolio.git
   ```
2. Open `index.html` in any modern web browser or use a simple local server:
   ```bash
   # Using Python
   python -m http.server 3000
   
   # Or using VS Code Live Server extension
   ```
