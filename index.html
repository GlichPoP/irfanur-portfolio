PROBAHO CRM Solutions

Offline-First Enterprise Business Management & Retail Showroom Operations Platform

The Operational Problem

Retail showrooms and multi-district distributors frequently lose sales when internet connectivity drops. Cloud-dependent CRMs halt sales counters, create data sync lags, and lack native integration with local courier delivery workflows in Bangladesh.

The Technical Solution

Taught myself desktop application architecture to engineer an offline-first system using SQLite WebAssembly (sql.js) embedded in Electron and React 19. All data transactions write to local disk with sub-millisecond latency, guaranteeing 100% operational uptime without internet.

Key Capabilities Built into the App:

  • In-App Background Auto-Updater: Integrated update pipeline using GitHub CDN with real-time download percentage streaming and 1-click silent relaunch.
  • 64-District Logistics Engine: Configured dispatch templates for Pathao, Steadfast, and RedX with cash-on-delivery (COD) financial reconciliation.
  • Role-Based Access Control (RBAC): Separated administrative owner controls from sales staff with audit activity logging.
  • Thermal Invoicing & Barcodes: Automated printable invoice generator with branded watermarks and barcode scanning support.
